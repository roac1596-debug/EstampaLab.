# EstampaLab

Sitio escolar de muestra para promocionar playeras personalizadas.

- `index.html`: estructura semántica del sitio.
- `styles.css`: diseño, colores, tipografías y adaptación a móviles.
- `assets/`: imágenes WebP optimizadas.

## Activar GitHub Pages
En GitHub abre **Settings → Pages**. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y `/(root)`, y guarda. La URL pública aparecerá en esa misma sección cuando termine el despliegue.
